# Padrão obrigatório de saída dos próximos laboratórios

A V57 restaura e congela o seguinte padrão.

## 1. Estado científico

- revisão por pares: sim/não;
- novidade confirmada: sim/não;
- teoremas internos versus fatos da literatura;
- afirmações retiradas ou superseded;
- limites explícitos do resultado.

## 2. Conteúdo matemático

- definições;
- teorema central;
- prova detalhada;
- corolários;
- contraexemplos às generalizações naturais.

## 3. Falsificação

- testes adversariais;
- busca exaustiva quando finita;
- testes de regressão para erros anteriores;
- separação entre prova e evidência.

## 4. Reprodutibilidade

- núcleo executável;
- verificador principal;
- verificador independente sem importar o núcleo principal;
- resultados serializados;
- comandos esperados;
- hashes e manifesto.

## 5. Comunicação

- resumo técnico;
- resumo para leigos;
- tabela de resultados;
- índice de promoção;
- índices de progresso;
- distância até P versus NP;
- contexto congelado da próxima versão.

## 6. Publicação

Nenhum número de validação pode aparecer no README do repositório sem que o código capaz de reproduzi-lo esteja commitado na mesma branch.
