# Laboratory V95 — balanced canonical loaders and PP-hard canonical decisions

## 1. Canonical halving sequence

For a Boolean circuit

```text
C=(C_0,...,C_{M-1}):{0,1}^N -> {0,1}^M
```

let `S_0={0,1}^N`. Recursively, after a prefix `y_<j`, define

```text
S_j={x : C_<j(x)=y_<j},
c_b(j)=|{x in S_j : C_j(x)=b}|.
```

The V92 rule chooses

```text
y_j=0  iff  c_0(j)<=c_1(j),
y_j=1  otherwise,
```

and lets `S_{j+1}` be the chosen child. At `M=N+1`, repeated halving guarantees
that the final canonical word is outside the range.

V94 proved PP-completeness for exact child comparison at an arbitrary supplied
prefix, but its hard prefix was not generated by this rule. V95 removes that
gap.

## 2. Balanced-definition canonicalization lemma

For any binary Boolean function `f:{0,1}^2->{0,1}`, define the ternary output
function

```text
D_f(z,a,b)=z XOR f(a,b).
```

### Lemma 2.1 — exact balance under a fresh definition variable

Let `p` be any prefix determined by earlier outputs that do not depend on input
coordinate `z`. Then

```text
N_C(p0)=N_C(p1)
```

when the next output is `D_f(z,a,b)`.

**Proof.** On the set of inputs satisfying `p`, toggle only coordinate `z`.
Earlier outputs are unchanged because they do not depend on `z`. Since

```text
D_f(z XOR 1,a,b)=D_f(z,a,b) XOR 1,
```

the toggle is a fixed-point-free involution between the zero-child and the
one-child. QED.

### Corollary 2.2 — the canonical bit is zero

Under the V92 tie rule, the next canonical bit is `0`. Conditioning on that bit
imposes exactly

```text
z=f(a,b).
```

For every assignment to all other coordinates, there is exactly one value of
`z` satisfying the canonical constraint.

### Theorem 2.3 — composable balanced loader

Let `A` be any acyclic Boolean computation with fan-in at most two. Introduce one
fresh circuit-input coordinate `z_i` for every internal wire and, in a
topological order, append the output

```text
D_{f_i}(z_i,u_i,v_i)
```

for the gate that defines that wire. Then every one of these output bits is
canonically `0`. After conditioning on the whole all-zero prefix, each assignment
to the original source coordinates has exactly one extension to all `z_i`, and
the extension gives the correct values of every wire of `A`.

**Proof.** Apply Lemma 2.1 successively. At step `i`, coordinate `z_i` is absent
from every earlier output by topological construction, so that step is an exact
tie and the canonical bit is zero. Corollary 2.2 fixes the correct wire value
uniquely. Induction gives the claimed bijection. QED.

### Interpretation

This is the composable forcing lemma requested by the V95 contract. The
canonical rule can install an arbitrary bounded-fan-in deterministic computation
without ever solving a hard count comparison: every loader step is a structural
50/50 tie.

## 3. A fixed seven-type local language

For the hardness compiler, arbitrary binary functions are unnecessary. It uses
only the following fixed types.

For `alpha,beta in {0,1}`,

```text
ORDEF_{alpha,beta}(z,a,b)
  = z XOR ((a XOR alpha) OR (b XOR beta)).
```

There are four such ternary functions.

Also use

```text
ANDDEF(z,a,b)=z XOR (a AND b),
```

and the ternary selector gate

```text
H(s,t0,t1)= NOT t0,  if s=0,
             t1,      if s=1.
```

Finally use a projection output for harmless padding. Thus the compiler needs
seven fixed output types, all of locality at most three.

## 4. Canonically loading two 3-CNF truth values

Take two nonempty 3-CNF formulas `F0,F1` over the same `n` source variables.
Clauses of width below three can repeat literals, so exact width three loses no
counting information.

For each clause

```text
(l1 OR l2 OR l3)
```

introduce two fresh input coordinates and load

```text
u = l1 OR l2,
v = u OR l3
```

with two signed `ORDEF` outputs. Combine all clause-value coordinates of each
formula by a binary AND chain loaded with `ANDDEF`. Let the resulting truth
coordinates be `t0,t1`.

If formula `F_c` has `r_c>=1` clauses, this uses

```text
3*r_c - 1
```

fresh definition coordinates. Let

```text
q = 3*(r_0+r_1)-2
```

be the total number of loader outputs.

Add one further free source coordinate `s` as a selector. The total number of
circuit inputs is

```text
N = n + 1 + q.
```

By Theorem 2.3, the first `q` canonical output bits are exactly

```text
0^q,
```

and after them the prefix fiber contains exactly one extension of every pair
`(x,s)`, with `t0=F0(x)` and `t1=F1(x)`. Its size is therefore `2^(n+1)`.

## 5. The PP-complete comparison appears as the next canonical bit

Let

```text
A=#sat(F0),
B=#sat(F1).
```

Place `H(s,t0,t1)` immediately after the balanced loader prefix.

### Lemma 5.1 — exact child counts of the selector gate

At prefix `0^q`,

```text
N_C(0^q 0) = A + (2^n-B),
N_C(0^q 1) = (2^n-A) + B.
```

**Proof.** On selector branch `s=0`, `H=NOT t0`, so `H=0` on exactly the `A`
assignments satisfying `F0`, and `H=1` on the remaining `2^n-A` assignments.
On selector branch `s=1`, `H=t1`, so `H=0` on exactly `2^n-B` assignments and
`H=1` on exactly `B`. Add the two selector branches. QED.

### Corollary 5.2 — comparison/bit identity

```text
N_C(0^q 0) <= N_C(0^q 1)
iff
A <= B.
```

Hence the next V92 canonical bit is

```text
0 iff #sat(F0)<=#sat(F1),
1 otherwise.
```

## 6. Exact minimal stretch

The circuit currently has `q+1` outputs: the `q` canonical loader gates followed
by `H`. Since

```text
N=n+1+q,
```

append exactly `n+1` harmless projection outputs. The final output length is

```text
M=(q+1)+(n+1)=N+1.
```

Every output depends on at most three circuit-input coordinates. Thus the entire
reduction lies inside stretch-one `NC0_3` range avoidance.

## 7. Canonical-next-bit hardness theorem

V94 Lemma 3.1 established that

```text
COMPARE-#3SAT_<=
 = {(F0,F1): #sat(F0)<=#sat(F1)}
```

is PP-complete.

### Theorem 7.1 — PP-hard canonical next bit

For the fixed seven-type language above, computing a specified next bit of the
V92 canonical halving sequence is PP-hard even for `NC0_3` circuits with
`M=N+1`, under the stronger restriction that every previous canonical decision
is an exact tie and the previous canonical prefix is syntactically `0^q`.

**Proof.** Map `(F0,F1)` to the compiler of Sections 4--6 and ask for output bit
`q`. Theorem 2.3 proves that the preceding prefix is genuinely the canonical
prefix, not an arbitrary promise. Corollary 5.2 identifies bit `q` with the
PP-complete source comparison. QED.

### Corollary 7.2 — exact canonical-word computation is PP-hard

Any algorithm that outputs the complete V92 canonical halving word for every
stretch-one `NC0_3` circuit can be used to solve `COMPARE-#3SAT_<=` by reading
bit `q` of the compiled word.

Therefore, if that exact canonical-word function were computable in deterministic
polynomial time, then `P=PP`; since `NP` is contained in `PP`, this would also
imply `P=NP`.

This is a barrier for the **specific canonical policy**, not a hardness theorem
for the total search problem `NC0_3-Avoid`.

## 8. Why the V94 obstruction disappears

V94 tried to use outputs whose accepting value `1` directly enforced each
constraint. Its first functional-definition predicate was balanced, so the V92
tie rule selected `0`, while the reduction required `1`.

V95 changes the representation rather than fighting the tie: the output itself
is an **error bit**. Correct computation is represented by output zero. A fresh
definition variable makes the error bit exactly balanced, and tie-zero now does
precisely what the reduction wants. This remains true after arbitrary earlier
balanced definitions and is therefore composable.

## 9. Executable finite audit

The implementation exhausts all ordered pairs of signed three-literal clauses
over two source variables. There are 64 clauses and 4,096 ordered pairs.

For each compiled circuit it checks:

```text
N=7, M=8, q=4,
all four loader decisions are exact ties,
canonical loader prefix = 0000,
final child counts match Lemma 5.1,
canonical bit q matches #sat(F0)<=#sat(F1),
the complete canonical word is outside the circuit range.
```

Aggregate audit:

```text
4,096 source pairs,
1,888 equal-count source pairs,
2,208 strict source pairs,
16,384 balanced loader decisions,
0 loader-prefix failures,
0 final-count mismatches,
0 comparison-bit mismatches,
0 canonical outputs in the range.
```

The finite audit validates the implementation only. Theorems 2.3 and 7.1 are
symbolic and do not depend on enumeration.

## 10. Scope and nonclaims

V95 proves PP-hardness of reproducing the exact V92 canonical trajectory. It
does **not** prove PP-hardness of finding an arbitrary string outside the range,
does not show that every avoidance algorithm implicitly solves the canonical
next-bit problem, does not improve the Huang-Li-Zhong stretch-one runtime, does
not trigger a published circuit-lower-bound transfer, does not establish
novelty or peer review, and does not resolve P versus NP.
