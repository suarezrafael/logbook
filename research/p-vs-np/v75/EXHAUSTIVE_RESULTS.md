# V75 finite verification results

All numbers below are deterministically regenerated by `v75_symbolic_prefix.py` and compared byte-for-structure with `RESULTS.json` by the primary verifier.

## Exhaustive binary positive-stretch census

The census enumerates all `16^3 = 4,096` circuits with `n=2`, `m=3`, common support `[0,1]`, and every possible two-input Boolean truth table at each output.

| Check | Total |
|---|---:|
| Circuits | 4,096 |
| Exact output coefficients | 32,768 |
| Exact prefix evaluations | 61,440 |
| Incrementally constructed avoided outputs | 4,096 |
| Maximum arithmetic operations in one DAG | 11 |
| Maximum dynamic reevaluations in one search | 40 |

Every symbolic coefficient equals the direct truth-table preimage count. Every prefix value equals the direct sum over matching outputs. Every dynamic update equals a fresh topological arithmetic evaluation, and every final target has zero direct preimages.

Across the exhaustive census, the generated DAGs contain 41,176 arithmetic operations in total. The complete searches perform 85,586 dynamic arithmetic reevaluations. The sum of all paired-variable dependency-cone sizes is 109,896; each search obeys the audited `dynamic <= 2 * cone-sum` bound.

The first frozen witness has boundary width four on both trees. Its balanced DAG uses 67 arithmetic operations, external path length 16, dependency-cone sum 278, and 187 dynamic reevaluations. Its caterpillar DAG uses 68 arithmetic operations, external path length 20, dependency-cone sum 296, and 221 dynamic reevaluations. Both construct output zero, which direct enumeration confirms is absent.

These finite measurements illustrate depth sensitivity; they do not prove that balanced trees always reduce the exact operation count or dynamic work on every instance.

## Interpretation

The computations validate the symbolic recurrence, coefficient semantics, prefix substitution, dynamic update engine, and exact depth accounting on the tested domain. They do not establish an automatic balancing transformation, an unrestricted avoidance algorithm, a lower bound in a standard model, or a P-versus-NP consequence.
