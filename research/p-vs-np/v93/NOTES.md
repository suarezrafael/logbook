# V93 notes

The decisive distinction is information-theoretic, not runtime-based: two explicit circuits can expose exactly the same frozen certificate `AS(C)` while requiring different canonical first bits, and can even have no common avoided word. Therefore no optimization of a decoder whose input remains only `AS(C)` can repair the model.

Any successor must add genuinely new information, such as prefix-conditioned counts/relations, a richer decomposition, or another theorem-native output interface.
