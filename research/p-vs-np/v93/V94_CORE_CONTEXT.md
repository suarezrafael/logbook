# V94 core context — child-count sign as a fixed-language counting problem

## Mission

V93 closes global support+constant-syndrome certificates as a general comparison oracle. V94 must not add more information of the same global affine type and call it progress.

The next object is the actual V92 primitive:

```text
Delta(C,p,j) = N(p0)-N(p1).
```

The required bit is the sign of `Delta`, with ties selecting zero.

## First target

Translate a prefix of an `NC0_3` circuit into a Boolean #CSP instance over the fixed local gate relations induced by the truth tables. Determine whether deciding

```text
N(p0) <= N(p1)
```

for arbitrary consistent prefixes is complete for a standard comparison-counting class (for example PP / Compare-#P) for one explicit ternary gate language, while preserving bounded locality and an explicit stretch embedding.

This is a barrier theorem target, not permission to claim hardness of the canonical sequence automatically.

## Positive track

In parallel, identify fixed ternary languages for which the two child partition functions admit polynomial-time evaluation or sign comparison. Affine/product-type languages are expected controls. Any positive result must state the exact language and a deterministic canonical-bit evaluator.

## Mandatory separation

V94 must keep separate:

1. arbitrary-prefix child comparison;
2. prefixes generated by the V92 canonical policy;
3. construction of an avoided output without exact comparison.

Hardness of item 1 does not imply hardness of item 2 or 3.

## Baseline

Huang-Li-Zhong ITCS 2026 Theorem 1.14 gives `O(n*2^(n/2))` for `NC0_3-Avoid[n,n+1]`. V94 should either explain a standard-model obstruction to replacing its traversed-space comparison by polynomial exact counting, or isolate a fixed-language tractable branch that genuinely improves the evaluator.

## Promotion rule

Promote only with one of:

- a parsimonious/metric reduction proving a standard counting-comparison hardness theorem with exact quantifiers;
- a dichotomy-style tractable language theorem with an implemented canonical comparator;
- a theorem showing that canonical prefixes avoid the arbitrary-prefix hardness construction.

Finite censuses alone are not promotion.
