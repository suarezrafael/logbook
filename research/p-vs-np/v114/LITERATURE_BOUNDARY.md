# V114 literature boundary

## Hardness source

The reduction starts from the classical directed two-disjoint-paths problem.

Primary reference:

- S. Fortune, J. Hopcroft, and J. Wyllie, **The directed subgraph homeomorphism problem**, *Theoretical Computer Science* 10 (1980), DOI `10.1016/0304-3975(80)90009-2`.

The standard consequence used here is that, given a digraph and two ordered terminal pairs, deciding whether there are two vertex-disjoint directed paths connecting the prescribed pairs is NP-complete even though the number of pairs is fixed at two.

A recent calibration source restating the classical boundary is:

- M. Bentert, D. Cavallaro, A. Heindl, K.-i. Kawarabayashi, S. Kreutzer, and J. Schröder, **The Directed Disjoint Paths Problem with Congestion**, SODA 2026, DOI `10.1137/1.9781611978971.82`.

V114 does not claim either directed-disjoint-path hardness result as new.

## What V114 adds internally

The internally proved step is a polynomial reduction from directed `2-DDP` into a restricted signed-MUX return-selection problem used by the V109--V113 research line.

The reduction preserves the features required by the laboratory:

- valid essential ternary signed MUX outputs;
- one fixed repeated-selector first pair with opposite first-branch source phases;
- gate-simple return semantics;
- target compatibility using the existing MUX implication rule;
- exact positive stretch `m=n+1`; and
- an explicit zero-overlap compatible bypass showing that the hard one-extra shared gate is not a common dominator.

The theorem is therefore a barrier to a generic guessed-extra-gate completion oracle, not a restatement that directed disjoint paths is hard.

## Boundary against stronger hardness claims

The reduction deliberately leaves a compatible zero-overlap route pair in every generated instance.  Consequently it does **not** establish NP-hardness of the `Delta=1` regime from V113.

It also does not establish NP-hardness of the question

```text
Does any target-compatible return pair exist?
```

because the explicit bypass already makes that answer yes on every reduction instance.

The NP-complete decision predicate proved in V114 is narrower and exact:

```text
Does the fixed first pair admit a target-compatible return pair
with exactly one shared return gate, used with opposite MUX branches?
```

That is the branch-oracle subproblem relevant to the naive Track-A strategy.

## Research consequence

After V114, an excess-overlap algorithm should not treat a guessed gate `g` as an arbitrary waypoint and expect ordinary flow to complete the two routes.  A viable positive result must exploit additional structure, for example a conflict certificate generated by V113's rejection of the entire minimum-overlap face, a restricted directed graph class, or another parameter controlling the cyclic linkage difficulty.

Novelty of the MUX-specific reduction has not been externally reviewed or confirmed.
