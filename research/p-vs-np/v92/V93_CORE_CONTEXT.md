# V93 core context — high-width child-count compression gate

## Mission

V93 may study only the first open bridge left by V92:

```text
Given a canonical prefix p, compare the exact child counts N(p0) and N(p1),
or certify that one child is empty, on high-width local circuits faster than
the Huang–Li–Zhong traversed-space bound.
```

The output policy is frozen by V92. Changing coordinate order, tie breaking, or suffix completion is not progress.

## Admissible outcomes

V93 is promotable with one of:

1. a quantified compression theorem for the connected preimage components that improves the worst-case exponent in a named locality/stretch regime;
2. a zero-detection procedure that avoids exact counting but still implements the canonical policy or a checked transfer-accepted single-valued policy;
3. a reduction to a standard counting, communication, proof, tensor, or branching model with a rigorous upper or lower bound;
4. a barrier theorem showing that a precisely defined representation cannot beat the HLYZ bound, followed by closure of that representation.

## Required parameter target

Before coding, V93 must choose one exact target row:

| Class | Stretch | Required complexity | Consequence |
|---|---|---|---|
| selected `NC0_k` class | explicit `m(n)-n` | explicit time/oracle class | named theorem number |

No experiment is authorized until all four cells are filled from a primary source.

## Barrier gate

A communication-complexity route must pass the Chen–Hu–Ren algebrization audit from V91. A new component census or another low-width optimization does not satisfy the V93 implication rule.

## Stop rule

If no standard-model compression or obstruction can be formulated, close the high-width prefix-count representation and move to a different theorem-native target rather than accumulating finite support examples.
